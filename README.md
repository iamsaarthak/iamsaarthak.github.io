# Sarthak Devkule Portfolio

A single-page portfolio website for Sarthak Rajendra Devkule.

## Publish for free with GitHub Pages
1. Create a free GitHub account if you don't already have one.
2. Create a **public** repository named `<yourusername>.github.io`.
3. Upload `index.html` and `style.css` to the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/root`.
6. GitHub will publish the site at `https://<yourusername>.github.io/`.

GitHub Pages supports static HTML/CSS/JS sites and is available with GitHub Free for public repositories.
